# Editorial Idea Analysis Skill

Return a numbered list of no more than five distinct ideas. Use these exact
labels for each idea:

1. `Title:`
2. `Central Story:`
3. `Opening Hook:`
4. `Target Audience:`
5. `Emotional Appeal:`
6. `Why People Might Watch:`
7. `Suggested Video Format:`
8. `Supporting Sources:`
9. `Potential Problems or Fact Checks:`

Keep the supporting sources limited to URLs or source titles included in the
provided research. Mention when the supplied evidence supports only a broad
content theme rather than a particular factual story.
