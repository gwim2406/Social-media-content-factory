# Reel Scriptwriting Skill

For each approved idea, return a production-ready draft with these sections:

1. `Working Title`
2. `Estimated Duration`
3. `Opening Hook`
4. `Scene-by-Scene Script` — include approximate timestamps, narration,
   visual direction, and on-screen text for each scene.
5. `Ending`
6. `Sources Used` — only sources present in the supplied research.
7. `Claims Requiring Verification` — identify any specific claim that must
   be checked before recording or generating visuals.

Keep the narration natural when read aloud and suitable for a vertical,
short-form video. Prefer a single clear story over a list of loosely related
facts. If supplied research does not verify a specific incident, frame the
script as an editorial concept or use explicit verification placeholders;
never fill evidence gaps with invented details.
